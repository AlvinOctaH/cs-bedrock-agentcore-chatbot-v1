# 01 — Setup: Tools, Credentials, Model Access

## 1. Prerequisites

| Requirement | Detail |
|---|---|
| AWS account | Amazon Bedrock + Bedrock AgentCore enabled; work in **us-east-1** |
| AWS CLI | v2, configured (`aws sts get-caller-identity` must work) |
| Python | 3.9+ with `boto3` 1.43+ |
| Model access | **Amazon Nova Pro** (`us.amazon.nova-pro-v1:0`) |

> Do **not** rely on the harness default model: it requires an AWS Marketplace
> subscription that Udacity lab accounts cannot complete. This project pins
> `us.amazon.nova-pro-v1:0` everywhere (harness, `chat.py`, evaluation judge).

## 2. Credentials (Udacity Cloud Lab)

Udacity labs give **temporary credentials** (access key, secret key, session token)
that expire after a few hours:

```bash
aws configure set aws_access_key_id     <ACCESS_KEY>
aws configure set aws_secret_access_key <SECRET_KEY>
aws configure set aws_session_token     <SESSION_TOKEN>
aws configure set region us-east-1
aws sts get-caller-identity
```

## 3. Python environment

```bash
cd starter
python -m venv venv
venv\Scripts\activate            # macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
```

## 4. Files you work with

| File | Role |
|---|---|
| `starter/system_prompt.txt` | **Main deliverable** — the chatbot's behaviour |
| `starter/online_shop_faq.md` | FAQ injected into the prompt via `{{FAQ}}` |
| `starter/harness-tests.json` | Your test suite (copied from `harness-tests-template.json`) |
| `starter/agentcore_config.json` | Generated by `setup_gateway.py` / `create_harness.py` — IDs and ARNs for later scripts (git-ignored) |

## 5. Build order

```
01 setup → 02 tool stack + gateway → 03 write the prompt → 04 create harness + chat
        → 05 test suite + Bedrock Evaluations → 06 evidence + clean-up
```
